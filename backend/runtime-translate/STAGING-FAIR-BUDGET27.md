Duplicate known sources are free, including after label deletion and recreation, because the private work ledger persists. A new revision, app or user is new work. Character budget failures roll back both the source and ledger insertion. Capabilities share the account budget, so capability reissue cannot replenish character allowance.

The database canonical response cache is keyed by account/app/revision.
