The embedded generic Arabic table is intentionally empty. Per-app online capability configuration must match the exact bundle, revision and installation. Native activation verification and capability expiry remain fail-closed. The app signing client accepts a Kat-only pending result only with a complete persisted receipt whose scope and source set match the request.

Only original untranslated UI strings pass through the existing conservative privacy screen. Raw dated history is never sent. A strictly validated Gregorian date or short ASCII list number may be split locally from a finite exact reviewed UI suffix. Only that suffix is eligible for queueing, and the original prefix is reassembled locally. Unknown suffixes, invalid dates, leading whitespace or formatting, and other numeric histories stay local. These are not global privacy filter exceptions.

The serialized worker sends at most sixteen strings and 2048 UTF-16 units per request, with 128 pending strings and a rolling 128-attempt minute budget. Unaccepted work retries at one, five and fifteen minutes and stops after four attempts. A successful durable receipt stops duplicate missing submissions and schedules bounded dictionary refreshes. Foreground refresh is debounced to once per minute. Superseded delayed timers are inert, so new work does not wait behind an old fifteen-minute retry.

Dictionary entries are versioned and revision-scoped, with at most 2048 cached entries and one MiB serialized cache or refresh response. Kat-approved entries cannot be overwritten by Gemini entries. Generic HTTP 403 does not create a permanent revocation marker. Explicit local revocation uses a separate marker, and expiry remains authoritative. Redirects, cookie storage and credential storage are disabled. Missing responses retain the smaller 64 KiB limit.

Changed dictionary entries trigger a debounced main-thread reapply to weakly tracked UIKit targets. The original source and attributed styling are retained, so subsequent versions do not translate already translated Arabic. Host text changes and clearing a value replace the remembered source. Public redraw and layout invalidation are requested for rendered views. SwiftUI coverage is not universal, and the retained-text fixture must empirically prove its supported path rather than counting a redraw call as translation success.

Missing coverage presents the exact requested centered native Arabic alert with a موافق button. It has no timeout and never interrupts an existing modal. The once-per-app flag is persisted only after visible presentation. Resolving a queue does not dismiss a notice the user is reading, and foreground handling retries a previously deferred notice.

The local missing diagnostic log remains app-local and is never uploaded. It is bounded to one MiB, 1024 distinct entries per process, sixteen queued writes and 4096 UTF-16 units per sample without splitting surrogate pairs. File opens refuse symlinks and require a regular single-link file with mode 0600.
