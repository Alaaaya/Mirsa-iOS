Mirsa clean-room public ABI references, reviewed November 25, 2026.

No SayoSign, SayoHook or other GPL implementation was read or copied. Only the public API declarations and documentation listed here were used for compatibility. Our implementation uses Apple's Objective-C runtime and a separately attributed BSD fishhook dependency.

Substrate declarations were verified against the public Theos compatibility header at https://github.com/theos/lib/blob/master/CydiaSubstrate.framework/Headers/CydiaSubstrate.h and API documentation at https://www.cydiasubstrate.com/api/c/MSGetImageByName and https://www.cydiasubstrate.com/api/c/MSFindSymbol. MSImageRef is an opaque const struct MSImage pointer, not a dlopen handle. MSImageAddress exposes the borrowed native Mach-O header. This shim identifies images by exact loaded dyld path and validates header identity before use. Scoped symbol lookup cannot accidentally return a dependency's export. Leading Mach-O underscores are accepted.

libhooker declarations were verified against its public header revision 4f85a68daebaf7456c66e1f55184dca118022397 and the official 1.6 documentation at https://libhooker.com/docs/Functions.html, https://libhooker.com/docs/Structs/LHFunctionHook.html, https://libhooker.com/docs/Structs/LHFunctionHookOptions.html, https://libhooker.com/docs/Structs/LHMemoryPatch.html, https://libhooker.com/docs/Enums/LIBHOOKER_ERR.html and https://libhooker.com/docs/Enums/LHOptions.html. The current docs describe LHHookFunctions as returning errors, so successful calls return LIBHOOKER_OK (zero), not a historical hooked-count convention. LHFunctionHook is four pointers, size 32 on arm64. The options member is at offset 24. LHFunctionHookOptions is an enum plus an int, size 8. Nonzero instruction/register options fail explicitly.

The substitute public API header at https://raw.githubusercontent.com/comex/substitute/master/lib/substitute.h is explicitly public domain / CC0. Only its declarations and API comments were consulted. substitute_function_hook has three pointers and a 32-bit options field, padded to size 32 on arm64. substitute_image contains intptr_t slide, void *dlhandle and const void *image_header, size 24. substitute_hook_objc_message uses a bool pointer for created_imp_ptr. This shim returns an existing IMP, never allocates a superclass trampoline, and writes false to that output. substitute_find_private_syms retains the documented zero return with NULL per missing symbol, but only searches exported symbols here. Its name does not imply implemented private-symbol parsing. Record output requests and nonzero per-hook options are unsupported.

The ElleKit README at https://github.com/tealbathingsuit/ellekit recommends the public Substrate or libhooker APIs. Public header revision 1017a0d09606ea49ba8bc4d6cccc530d372e640e was checked for declarations only. This shim supports those documented compatibility entry points within the limitations in README.md. It does not export a guessed EKHookFunction or undocumented Swift ABI.

fishhook is the official Facebook BSD-3-Clause source, pinned to commit aadc161ac3b80db07a9908851839a17ba63a9eb1. The three vendor files are byte-exact. Their SHA256 values are 48f51e1a36d9013501381fdf31a3e9c838938ebf8bb39e0e3a7ac119aa59b61b for fishhook.c, 5432b81bd302956adcbfc8836af74e47dd38748d5078495cbe1b5bea62180120 for fishhook.h, and 0d6de56134ac05ffce391c697bb046c83cab012a4670114e1f0847ecf59b2c2e for LICENSE. prepare-fishhook.py creates a temporary derivative that delegates stores to our checked helper and stops allocation-failed traversal. Only rebind_symbols_image is invoked, so no dyld callback retains caller original-output storage.
