The optional Mirsa Home Screen is an independently written SwiftUI implementation,
visually inspired by NightVibes33/FlekDeck (https://github.com/NightVibes33/FlekDeck).
FlekDeck is licensed under GNU AGPL version 3. No FlekDeck code, images, wallpaper,
or other assets are redistributed here. Existing Mirsa and dependency licenses
are unchanged. Upstream names and notices remain attributed in Settings > About.

The reference uses a three-column springboard, frosted icon cards, page indicators
and wallpaper. Mirsa retains its own launching, signing, app actions and tabs.
